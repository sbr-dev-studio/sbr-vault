**SbrVault** is a high-security, lightweight, and modern personal password manager and encrypted vault for Windows. Built natively with **C# .NET** and **WPF**, it delivers maximum privacy, strict local data isolation, and instant performance.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🛡 **Authenticated Encryption** | All stored records are protected using **AES-256-GCM**. |
| 🔑 **Argon2id Key Derivation** | Industry-standard hashing algorithm to resist hardware brute-force attacks. |
| 💻 **Local-First Privacy** | Zero cloud dependency. Vault files stay strictly on your local device. |
| ⚡ **Modern WPF Interface** | Fast, reactive, and user-friendly desktop user experience. |
| 📦 **Portable Release** | No complex installation needed — extract and run anywhere. |

---

## 🚀 Quick Start Guide

1. Head over to the **[Official Releases](../../releases)** section.
2. Download the latest compiled package (`SbrVault-v0.1.0.zip`).
3. Extract the archive into any folder on your computer.
4. Launch `SbrVault.exe`.

---

## 🛡 Security Architecture

* **Encryption Standard:** AES-256-GCM (Galois/Counter Mode).
* **Key Derivation Function (KDF):** Argon2id.
* **Memory Protection:** Key handling protocols designed to minimize plaintext exposure in RAM.
* **Storage Control:** Dedicated encrypted vault files with strict access control.

---

## 💻 System Requirements

* **OS:** Windows 10 / Windows 11 (64-bit)
* **Framework:** .NET Desktop Runtime 8.0 *(or self-contained)*
