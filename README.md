\# SbrVault



High-security personal password \& encrypted vault manager built with C# .NET and WPF (AES-256-GCM, Argon2id). Designed with privacy, data isolation, and performance in mind.



\---



\### 🚀 Download \& Installation



1\. Navigate to the \*\*\[Releases](../../releases)\*\* section on the right side of this page.

2\. Download the latest compiled archive (`.zip`).

3\. Extract the contents to your preferred directory.

4\. Run `SbrVault.exe` to launch the application.



\---



\### 🔒 Security \& Privacy



\* \*\*Encryption:\*\* AES-256-GCM authenticated encryption.

\* \*\*Key Derivation:\*\* Argon2id hashing algorithm for maximum protection against brute-force attacks.

\* \*\*Data Control:\*\* Local vault file storage with strict encryption key handling.
